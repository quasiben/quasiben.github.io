quasiben.github.io
==================

This is a [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) site managed with
[uv](https://docs.astral.sh/uv/).

## Local development

Install the project environment:

```bash
uv sync
```

Build the site:

```bash
uv run mkdocs build
```

Start the local development server:

```bash
uv run mkdocs serve
```
