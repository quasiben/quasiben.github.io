quasiben.github.io
==================

This is a [Lektor](https://www.getlektor.com/) site managed with
[uv](https://docs.astral.sh/uv/).

## Local development

Install the project environment:

```bash
uv sync
```

Build the site:

```bash
uv run lektor build
```

Start the local development server:

```bash
uv run lektor server
```
